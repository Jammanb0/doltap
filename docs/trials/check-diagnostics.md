# 013 검사 메시지 검증

[시험 보고서 목록](README.md) · [자동 시험](automated/diagnostics.md) · [사용 안내](../../guide/diagnostics.md)

## 확인한 범위

Windows / Node v22.14.0에서 작업 트리의 CLI를 실행했습니다.
전체 시험 중 새 진단 시험은 16개이며, 파일별 실행 근거는 위 자동 시험 보고서에 있습니다.

| 항목 | 방법 | 관찰 결과 |
| --- | --- | --- |
| 진입점 오류 | 임시 골격의 CLAUDE.md 본문을 바꾸고 check·check --json 실행 | CLAUDE_IMPORT_MISSING 한 건, 원인·위치·다음 행동 표시, 양쪽 종료 코드 1 |
| 수정 후 검사 | CLAUDE.md를 @AGENTS.md 한 줄로 복원 | 문제 0개, 채우기 확인만 남고 종료 코드 0 |
| 중복 ID | 문서를 복사하고 두 시작 위치를 실제 파일 행과 대조 | 중복 위치와 먼저 발견한 범위를 함께 표시, 복사본 제거 뒤 문제 해소 |
| 이동 경로 | 필수가 아닌 등록 문서를 한글·공백 경로로 이동한 뒤 move-fix 적용 | 새 대상 위치 안내, 본문 보존과 재검사 통과 |
| 관계 재검토 | depends-on·produces·verified-by·update-with의 내용 변경과 검토 기록 | 만료 방향에 맞는 출발·도착·양쪽 변경 이유, 기록 후 안내 해소 |
| 경계 조건 | 대칭 관계의 ID 정렬 반전과 같은 ID의 자기 참조 | 선언 방향과 만료 방향에 맞는 이유 표시 |
| 읽기 전용 | 오류·미완료 복구 자료가 있는 프로젝트의 검사 전후 파일 대조 | check 실행으로 문서나 복구 자료가 바뀌지 않음 |
| 표 행 위치 | 잘못된 검토 판단·발급 상태를 넣고 출력 위치와 원문 대조 | 실제 표 행을 안내하고 복원 후 오류 해소 |
| 터미널 표시 | 실제 CLI의 오류와 재검토 출력을 읽고 사용 안내의 예시와 문자열 대조 | 안내 예시가 실제 오류 출력에 포함, 위치·설명·관련·다음 행동을 구분해 표시 |
| 안내 경로 | guide의 파서가 읽는 로컬 링크 대상 확인 | 66개 대상 경로 존재 확인 |
| 배포 구성 | npm pack --dry-run --json 실행 | 48개 파일 목록에 lib/diagnostics.mjs·guide/diagnostics.md 포함 |

배포 미리보기는 기본 npm 캐시 쓰기 권한 때문에 처음 실패했습니다. 별도 임시 캐시를
사용해 다시 실행했고 성공했습니다. 실제 패키지 업로드나 릴리즈는 실행하지 않았습니다.

## 원격 CI

main의 구현 커밋 62df7994b9f5b109db9ec33d566bc92508e901b4에서 실행한
[GitHub Actions 34973593958](https://github.com/Jammanb0/doltap/actions/runs/34973593958)이
성공했습니다. Ubuntu·macOS·Windows × Node 22·24의 여섯 작업 모두 npm test,
check template, check . 단계를 통과했습니다. 종료 기록의 후속 커밋과는 구분합니다.

## 해석 범위

CLI 관찰은 로컬에서 했으며 다른 운영체제의 자동 시험 근거는 위 원격 CI입니다.
외부 사용자가 안내만 보고 문제를 해결하는 과정은 확인하지 않았습니다.
코드·구조화 위치·다음 행동은 진단 정보를 제공하며 자동 수정이나 내용 검토를
대신하지 않습니다. 존재하지 않는 검사 폴더·잘못된 옵션은 기존 CLI 오류 경로를
유지하며 JSON 진단 배열의 대상이 아닙니다.
