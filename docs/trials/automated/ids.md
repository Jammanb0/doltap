[시험 보고서 목록](../README.md) · [시험 원본](../../../test/ids.test.mjs)

## 방법

발급·재발급·삭제 상태와 잠금을 검사한다. 동시 프로세스와 쓰기 실패를 사용해 충돌·잠금 정리를 확인한다.

- 실행: `node --test --test-reporter=tap test/ids.test.mjs`
- 실행일: 2026-09-13 (Asia/Seoul)
- 환경: Node v22.14.0, win32 x64
- 시험 대상: 이 명령을 실행한 시점의 작업 트리
- 판정 기준: 종료 코드 0, TAP의 전체·통과·나열된 하위 시험 수가 모두 일치
- 시험 파일 SHA-256: `4af9a5b12599aa809d927d5a07c08ca5bac149b53a215e466f79d4e548bcf4c3` (시험 파일만 식별하며 구현 전체의 해시는 아님)
