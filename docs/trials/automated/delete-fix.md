## 방법

Git 없는 임시 프로젝트에서 직접 삭제한 파일·문단의 ID와 참조를 정리한다. 이동·손상·일반 링크·범위 제한·CLI 미리보기 및 실패 복구를 대조한다.

- 실행: `node --test --test-reporter=tap test/delete-fix.test.mjs`
- 실행일: 2026-09-12 (Asia/Seoul)
- 환경: Node v22.14.0, win32 x64
- 시험 대상: 이 명령을 실행한 시점의 작업 트리
- 판정 기준: 종료 코드 0, TAP의 전체·통과·나열된 하위 시험 수가 모두 일치
- 시험 파일 SHA-256: `a632703d63c22ebf4bb4db73c0f5f2c4389f0383224f102b499c8b715b6af543` (시험 파일만 식별하며 구현 전체의 해시는 아님)
