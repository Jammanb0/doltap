- 실행: `node --test --test-reporter=tap test/review.test.mjs`
- 실행일: 2026-09-13 (Asia/Seoul)
- 환경: Node v22.14.0, win32 x64
- 시험 대상: 이 명령을 실행한 시점의 작업 트리
- 판정 기준: 종료 코드 0, TAP의 전체·통과·나열된 하위 시험 수가 모두 일치
- 시험 파일 SHA-256: `29dc37db0a9bc0f21f05381f1338a4fcc7a339071950de835fc05b5a1d310ea6` (시험 파일만 식별하며 구현 전체의 해시는 아님)
