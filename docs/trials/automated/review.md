## 방법

첫 검토, 관리 메타데이터, 필터, 경로 표기, 손상 기록을 재현한다. 다대일·일대다 관계의 검토 상태 변화를 각각 확인한다.

- 실행: `node --test --test-reporter=tap test/review.test.mjs`
- 실행일: 2026-09-12 (Asia/Seoul)
- 환경: Node v22.14.0, win32 x64
- 대상: 이 보고서와 함께 커밋된 코드와 템플릿
- 시험 파일 SHA-256: `3ba07af18c4544632e6babe5b022ab8b491b3327c6067309c7a371c97268c854`
