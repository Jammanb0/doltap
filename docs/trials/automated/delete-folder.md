# 등록 문서 묶음 삭제 시험

[시험 보고서 목록](../README.md) · [시험 원본](../../../test/delete-folder.test.mjs)

## 방법

폴더 안에 등록된 문서와 내부 순환 관계를 함께 삭제한다. 외부 참조, 미등록 파일 보존, CLI 미리보기, 실패 롤백과 부모 폴더 복원을 확인한다.

- 실행: `node --test --test-reporter=tap test/delete-folder.test.mjs`
- 실행일: 2026-09-14 (Asia/Seoul)
- 환경: Node v22.14.0, win32 x64
- 시험 대상: 이 명령을 실행한 시점의 작업 트리
- 판정 기준: 종료 코드 0, TAP의 전체·통과·나열된 하위 시험 수가 모두 일치
- 시험 파일 SHA-256: `711fc0b74d02afe7dbac435c4c4c5f0e6111366821c65cb063637d37a6562106` (시험 파일만 식별하며 구현 전체의 해시는 아님)

## 결과

5개 실행, 5개 통과, 실패·건너뜀 0개. 다음은 실제 러너가 출력한 시험 이름이다.

| 번호 | 시험 | 결과 |
| --- | --- | --- |
| 1 | 묶음 삭제는 내부 순환 참조를 함께 지우고 외부 참조는 명시해야 제거한다 | 통과 |
| 2 | 등록되지 않은 텍스트와 마크다운은 보존하고 retained에 표시한다 | 통과 |
| 3 | 일반 링크와 혼합 본문·루트·잘못된 모드는 묶음 삭제하지 않는다 | 통과 |
| 4 | 묶음 삭제 실패는 모두 롤백하고 성공 뒤에도 파일과 부모 폴더를 복원한다 | 통과 |
| 5 | delete 폴더 CLI의 JSON 미리보기는 읽기 전용이고 apply는 빈 폴더까지 정리한다 | 통과 |

## 해석 범위

일반 폴더 삭제가 아니다. 등록된 문서만 삭제하며 일반 링크와 혼합 본문은 직접 정리한다. 원래 비어 있던 폴더까지 복원하지는 않는다.
