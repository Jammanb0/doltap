## 방법

임시 프로젝트에서 실제 CLI의 터미널·JSON·종료 코드를 비교한다. 중복 ID·깨진 링크·이동·검토 만료·손상 기록을 만들고 수정 뒤 재검사한다.

- 실행: `node --test --test-reporter=tap test/diagnostics.test.mjs`
- 실행일: 2026-09-15 (Asia/Seoul)
- 환경: Node v22.14.0, win32 x64
- 시험 대상: 이 명령을 실행한 시점의 작업 트리
- 판정 기준: 종료 코드 0, TAP의 전체·통과·나열된 하위 시험 수가 모두 일치
- 시험 파일 SHA-256: `89a58b19c305f0fea8f1f7cb0cf5f3d48fc24e41677c085863855866e0f9772e` (시험 파일만 식별하며 구현 전체의 해시는 아님)

## 해석 범위

로컬 CLI와 지정 입력의 진단을 검증한다. 원격 CI, 모든 오류 조합, 안내 문구만으로 사용자가 수습할 수 있는지는 별도 검증 대상이다.
