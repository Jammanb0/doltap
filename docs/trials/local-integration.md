# 로컬 통합 실행

[시험 보고서 목록](README.md)

실행일: 2026-09-12 (Asia/Seoul). 환경: Windows, Node.js 22.14.0.
자동 시험 파일 밖에서 실제 CLI와 생성 파일을 대조한 결과다.

## 폴더 이름 변경

방법: 독립 임시 폴더 `cairn`에 bin·lib·template·package.json을 복사하고 Git을
초기화했다. 그 안에 `init`으로 프로젝트를 만든 뒤 `map --json`을 저장했다.
임시 checkout을 `doltap`으로 옮긴 뒤 새 위치의 CLI로 map과 check를 다시 실행했다.

결과: 이름 변경 전후 map JSON이 같고 check 종료 코드가 0이었다. Git도 이동한
폴더를 작업 트리로 인식했다. 제품 코드에는 checkout의 절대 이름을 요구하는
참조가 없고 원격 저장소 이름은 설치 URL에 별도로 사용된다.

실제 작업 폴더는 이동하지 않았다. 열려 있는 작업과 저장된 프로젝트 경로가 그
폴더를 가리킨다. 실제로 바꿀 때는 해당 편집기·터미널 작업을 닫고, 부모 폴더에서
이름을 바꾼 뒤 새 경로로 프로젝트를 연다. GitHub 저장소 이름 변경은 별도 작업이다.

## 패키지 초기화

방법: `npm pack`으로 만든 tarball을 임시 위치에 풀고, 그 안의 CLI로 빈 프로젝트를
생성한 뒤 check를 실행했다. 포함 파일 목록에서 복구 자료·시험·개발용 임시 파일이
빠졌는지 확인했다.

결과: 34개 파일이 패키지에 포함됐고, 초기화한 프로젝트의 check는 문제 0개·종료
코드 0이었다. 공통 결정 문서와 plans/project.md도 template에서 복사됐다. 이전 위치의
.doltap/project.md는 생성되지 않았다. docs·test·scripts·복구 자료와
개발용 임시 파일은 패키지에 포함되지 않았다.
