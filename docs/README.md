# doltap 문서

이 폴더에는 두 가지 문서가 있습니다. doltap을 쓰는 방법을 설명하는 **사용 안내**와, doltap이
안내한 대로 실제로 동작하는지 확인한 **검증 기록**입니다.

| 폴더 | 무엇이 있나 | 이럴 때 읽습니다 |
| --- | --- | --- |
| [사용 안내](guide/README.md) | 시작하기, 표식과 관계, 작업 기록, 에이전트와 함께 쓰기, 명령·검사 항목 참고 | doltap을 써 보려 할 때, 명령이나 검사 결과의 뜻을 찾을 때 |
| [검증 기록](verification/README.md) | doltap 1.0.0을 무엇으로 어떻게 확인했는지와 그 근거 | 이 도구가 안내대로 동작하는지 먼저 확인하고 싶을 때 |

사용 안내는 npm 패키지에도 함께 들어가 설치한 폴더에서 바로 읽을 수 있습니다. 검증 기록은
이 저장소에서만 볼 수 있습니다.

이미 작업 중인 프로젝트에 doltap을 적용하는 절차는 저장소 맨 위의 [적용 절차](../APPLY.md)에
있습니다.
