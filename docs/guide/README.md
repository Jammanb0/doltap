# 사용 안내

doltap은 문서를 대신 써 주지 않습니다. 사람이나 함께 일하는 AI가 Markdown 문서를 평소처럼
고치고, doltap은 그 뒤에 **어디가 어긋났는지, 무엇을 다시 확인해야 하는지, 지금 하던 일이
어디 있는지**를 찾아 줍니다. 명령을 직접 실행해도 되고, 터미널을 쓸 수 있는 AI에게 맡겨도
됩니다.

## 처음이면 이 순서로 읽으세요

1. [시작하기](getting-started.md) — 설치하고 새 프로젝트를 만든 뒤, 두 문서를 관계로 잇고
   검토를 기록해 봅니다.
2. [표식과 관계](format.md) — 범위 표식과 세 가지 관계를 언제 어떻게 쓰는지 봅니다.
3. [작업 기록](workstreams.md) — 진행 중인 작업을 남기고 이어받고 보관하는 방법을 봅니다.

## 명령을 읽는 법

안내의 `doltap`은 doltap을 실행하는 명령을 줄여 쓴 것입니다. 소스를 받아 쓰는 경우
`node <doltap 폴더>/bin/doltap.mjs`에 해당합니다. [시작하기](getting-started.md)에서
실행 방법을 먼저 확인하세요. `<ID>`나 `<폴더>`는 실제 값으로 바꾸며 꺾쇠 자체는 입력하지
않습니다.

파일을 바꾸는 명령은 먼저 바뀔 내용만 보여 줍니다. 확인한 뒤 같은 명령에 `--apply`를
붙이면 씁니다. `init`만 빈 폴더에 바로 만듭니다.
