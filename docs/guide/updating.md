# 새 버전 받기

[사용 안내](README.md) · [시작하기](getting-started.md)

doltap 도구를 새로 받는 일과 프로젝트에 이미 적용한 문서를 바꾸는 일은 별개입니다. 도구를
업데이트해도 프로젝트의 `AGENTS.md`, `CLAUDE.md`, `.doltap/`는 저절로 바뀌지 않습니다.

## 도구 받기

Git으로 소스를 받았다면 **doltap 소스 폴더**에서 실행합니다. 적용한 내 프로젝트 폴더와
구분하세요.

```sh
git status --short
git pull --ff-only
node bin/doltap.mjs --version
```

첫 명령에 변경 파일이 나오면 먼저 정리합니다. `--ff-only`는 로컬과 원격의 이력이 갈라졌을
때 자동으로 합치지 않고 멈추는 옵션입니다. 기존 소스를 그대로 두고 싶으면 다른 폴더에 새로
받아도 됩니다. 그때는 이후 명령의 경로도 새 폴더로 바꿉니다.

## 받은 뒤에

새 버전에서 바뀐 점은 릴리즈 노트에서 확인합니다. 프로젝트 문서는 그대로 두고 `doltap check`를
실행해, 새로 생긴 검사가 알리는 곳이 있으면 고칩니다.

`template/`이 바뀌었더라도 이미 만든 프로젝트에는 반영되지 않습니다. 바뀐 템플릿에서 필요한
부분이 있으면 프로젝트의 `AGENTS.md` 같은 문서에 골라 옮깁니다.
