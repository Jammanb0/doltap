# 검사 메시지 개선

`doltap check`의 문제·확인 항목에서 원인, 수정할 위치와 다음 행동을 알 수 있게 합니다.

## 범위

- 검사 항목에 안정적인 코드, 구조화한 위치, 다음 행동과 관련 위치를 붙입니다.
- 중복 ID·낡은 경로·관계 재검토 안내를 구체화합니다.
- 터미널과 JSON이 같은 진단 정보를 사용하고, 기존 판정과 종료 코드를 유지합니다.
- 사용 안내와 실제 CLI 시험으로 수정 전후의 흐름을 검증합니다.

탐색용 브라우저 UI, 자동 수정 기능, 새 의존성은 포함하지 않습니다.

## 검증 조건

1. 대표 문제에서 고칠 위치와 다음 행동을 출력하고 수정 뒤 해당 항목이 사라집니다.
2. 재검토 안내가 기록 부재와 검토 대상 내용 변경을 구분하며, 정상 관계를 오탐하지 않습니다.
3. JSON의 기존 필드를 유지하고 추가 필드와 터미널 출력이 일치합니다.
4. 전체 시험과 저장소·배포 골격 검사, 시험 보고서 일치 검사를 통과합니다.

초기 범위는 로컬 검증까지였으며, 후속 사용자 승인에 따라 커밋·main 반영·푸시와
원격 CI 확인, 대작업 종료·아카이브·작업 브랜치 삭제까지 진행합니다.
