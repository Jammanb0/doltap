# 처음 쓰는 사람을 위한 안내 — 결정

## 사용자 요청대로 계획도 로컬 작업 브랜치에 둔다

- `이번만` 010의 작업 위치와 승인 범위

사용자가 009 종료 뒤 새 로컬 브랜치에서 작업하도록 지정했습니다. 계획 커밋도
이 브랜치에 둡니다. main만 보는 세션은 진행 중인 010을 찾을 수 없으므로 이어받을
때 이 브랜치를 선택해야 합니다. 009 작업 브랜치는 그대로 보존합니다.
