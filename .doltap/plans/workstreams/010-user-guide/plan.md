# 처음 쓰는 사람을 위한 안내 — 계획

1. 현재 설치 주소와 예시에 남은 저장소명을 정리한다. 역사·출처와 구분해 검색한다.
2. 개념과 대작업 흐름부터 설명하고 상황별 명령 안내를 만든다. 기존 GRAPH 내용을
   참고 문법으로 흡수해 없어진 기능이나 검증하지 않은 보장을 덧붙이지 않는다.
3. README·APPLY·프로젝트 안내를 새 가이드에 연결하고 package.json에 포함한다.
4. 내부 링크와 예시를 임시 프로젝트에서 확인한다. 009 CI에서 관찰된 기존 잠금 오류는
   별도 로컬 수정으로 보완하고 원격 실패와 로컬 검증을 구분한다. 실제 pack 내용과 init → check,
   전체 시험·두 check·시험 보고서 일치를 검사한다.
5. 실제 검증과 한계를 status에 남기고 로컬 커밋한다. main 반영·push·종료는 하지 않는다.
