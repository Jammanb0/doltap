# 처음 쓰는 사람을 위한 안내

문서 골격과 그래프를 처음 접한 사람이 작업의 시작부터 보관까지 이해하고,
상황에 맞는 명령을 선택할 수 있도록 사용 안내를 정리합니다.

## 범위

현재 설치 주소의 저장소명을 doltap으로 맞추고 guide에 개념·대작업 흐름·시작·
일상 조회·ID와 관계·이동과 삭제·검토·종료·선택적 훅·참고 문법을 나눕니다.
GRAPH.md의 내용을 흡수하고 README·적용 절차·배포 구성을 연결합니다.

## 완료 조건

- 처음 사용하는 사람이 대작업 생성 → 진행 → 완료·아카이브의 담당자와 문서 위치를 구분할 수 있다.
- 앵커와 ID, 일반 링크와 관계, 검토·발급·복구 기록의 역할을 설명한다.
- 실제 CLI에 맞는 예시와 내부 링크를 확인하고 guide가 배포 파일에 포함된다.
- 현재 설치 주소에 옛 저장소명이 남지 않으며 역사적 표현은 보존한다.
- 시험과 두 check, 보고서 일치 검사를 통과한다.
