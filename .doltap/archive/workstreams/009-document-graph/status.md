main에서 200개 시험과 check 두 종, archive-check를 다시 통과했습니다.
결과: 완료. 사용자 재승인으로 종료합니다. 작업 브랜치는 삭제하지 않고 보존합니다.

- 결정·전제·열린 질문의 HTML 주석 예시를 실제 선언에서 제외했습니다.

  --drop-links로 독립된 외부 관계 줄 제거를 명시하며 미등록 파일은 남깁니다.
  실패 롤백과 성공 후 파일·부모 폴더 복원을 시험했습니다.

  현재 결정 24개에 수명 표식이 있으며 옮길 곳으로 남은 결정은 없습니다.

- archive-check: 문제 0. 표식 검사와 담당 원본의 수동 대조는 별도입니다.
- check . 문제·확인 0, 시험 보고서 8개와 200개 시험 일치, pack dry-run 34개 파일입니다.
- 이번 빈 폴더 init → check와 git diff --check도 통과했습니다.

VS Code 기본 미리보기의 조각 이동은 이전 실행의 관찰입니다. 이번에 재실행하지
않았습니다. 실제 사용자 설정에 훅을 설치한 검증·독립 에이전트 행동 시험은
수행하지 않았습니다. Stop 어댑터는 로컬 입출력 시험입니다.
