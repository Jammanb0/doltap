# 검사 메시지 개선 — 계획

1. 판정이 내려지는 곳에서 진단 코드를 부여하고 공통 형식으로 위치·다음 행동을 만듭니다.
   기존 판정 조건을 바꾸지 않고 골격·그래프·검토 상태·아카이브 항목을 확인합니다.
2. 중복 ID와 경로 불일치에 관련 위치를, 재검토 안내에 기록 부재·내용 변경 이유를 붙입니다.
   관계 유형별 검토 만료 방향과 대칭 관계의 해시 순서를 대조합니다.
3. 터미널과 JSON 출력을 확장하고 읽는 법을 안내에 기록합니다.
   기존 JSON 필드·스키마 이름과 종료 코드를 유지합니다.
4. 대표 오류·정상 입력·수정 후 재검사를 시험하고 실제 CLI 출력을 확인합니다.
   전체 시험, 두 문서 검사, 파일별 보고서를 갱신·검증합니다.
5. 검증 근거와 남은 한계를 상태에 기록하고 미커밋 검토 대기로 둡니다.
