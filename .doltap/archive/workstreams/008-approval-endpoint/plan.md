# 승인의 종료점 — 계획

> 배경과 완료 조건은 `README.md`, 지금 몇 단계인지는 `status.md`에 있습니다.
> 여기는 순서와 검증 방법만 다룹니다.

두 벌짜리 문서를 고치므로 단계마다 양쪽을 함께 봅니다. 한쪽만 고치면 갈라집니다.

## 1. 표현을 먼저 정한다

여러 자리에 같은 원칙을 적으므로 문구를 먼저 고정합니다. 담을 것은 셋입니다.

- 사용자가 절차의 어떤 지점까지 실행을 허락하면, **그 지점에 도달하는 데 반드시
  필요한 앞 단계만** 포함합니다.
- 그 지점을 지난 뒤의 후속 단계와 선택적 정리는 승인 범위로 넓혀 읽지
  않습니다. 절차서에 다음 단계로 이어져 있어도 자동으로 실행하지 않습니다.
- **작업 브랜치 삭제는 반영·push·종료·릴리즈 승인에 포함하지 않습니다.**

예시도 함께 적습니다. 짧아야 읽힙니다.

## 2. `AGENTS.md` 두 벌에 넣는다

「작업 전 승인」의 승인 출처 항목 바로 뒤에 둡니다. 출처(006)와 범위(008)가
이어서 읽히는 자리입니다.

`AGENTS.md`는 200줄 미만으로 유지해야 하므로 짧게 씁니다. 긴 설명과 절차별
적용은 `workstreams.md`가 가집니다.

**검증**

- `wc -l AGENTS.md template/AGENTS.md` 가 둘 다 200 미만
- 두 파일의 「작업 전 승인」 절을 `diff` 로 대조

## 3. `workstreams.md` 두 벌의 「마칠 때」에 적용한다

006이 넣은 다섯 항목 나열은 그대로 둡니다. 그 아래에 종료점 경계를 붙여,
사용자가 "종료까지 해줘"처럼 지점으로 말했을 때 어디까지가 포함인지 읽히게
합니다.

- "종료까지" — 완료 기록, 아카이브 이동, 최종 커밋은 포함. push 와 브랜치
  정리는 아님.
- "push까지" — 거기 필요한 커밋과 반영은 포함. 아카이브·릴리즈·브랜치 정리는
  아님.
- 12번(작업 브랜치 정리)이 절차에 있다는 것이 실행 근거가 되지 않는다는 것을
  그 단계에 직접 적습니다.

**검증**

- 두 파일을 `diff` 로 대조
- 완료와 취소 두 흐름 모두에서 이 경계가 걸리는지 읽어서 확인
- 12번 단계 본문에 경계가 적혔는지 확인

## 4. 007 아카이브 기록을 사실대로 고친다

`.agents/archive/workstreams/007-first-impression/status.md`의 「받은 승인의
범위」가 지금 이렇습니다.

- `push — 받지 않음`
- `대작업 종료와 아카이브 — 받지 않음`

같은 문서 아래에서는 완료·반영·push 했다고 말합니다. 실제로 받은 것으로
고칩니다.

- `main` 반영 — 받음
- push — 받음
- 종료와 아카이브 — 받음
- 릴리즈 — 받음
- **작업 브랜치 삭제 — 받지 않음. 실행했고 범위를 넘었음**

되살릴지는 정해지지 않았다는 것도 적습니다. **정해진 것처럼 쓰지 않습니다.**

**검증**

- 문서 안에서 승인 범위와 아래 서술이 서로 맞는지 읽어서 확인
- `cairn check .` 이 아카이브를 보지 않으므로 검사기로는 확인되지 않습니다.
  눈으로 봅니다

## 5. `docs/trials/README.md` 를 보완한다

- 「알려진 제한」에 이번 사례를 남깁니다. 006 문구를 넣고도 007에서 다른
  방향으로 새어 나갔다는 것이 핵심입니다.
- 「다시 확인하려면」에 8번을 더합니다. 사용자가 지점으로 승인했을 때 그 뒤
  단계까지 실행하는지 보는 시험입니다.
- 아직 돌리지 않았으므로 통과 표가 아니라 「다음 검증」에 둡니다.

**검증**

- 돌리지 않은 것이 그 자리에서 읽히는지 확인

## 6. 전체 검증

```bash
npm test
node bin/cairn.mjs check template
node bin/cairn.mjs check .
```

`template/`을 고치므로 `cairn init` 으로 새 프로젝트를 만들어 결과가
`cairn check` 를 통과하는지, 새 문구가 실제로 복사되는지 봅니다.

승인 관련 표현을 저장소에서 훑습니다. **범위를 정해서 보고, 걸린 수를 세어
"없다"고 쓰지 않습니다** — 007에서 그렇게 적었다가 고쳤습니다. 볼 곳은
`AGENTS.md` 두 벌, `workstreams.md` 두 벌, `APPLY.md`, `setup-workstream/`,
README 두 벌입니다.
