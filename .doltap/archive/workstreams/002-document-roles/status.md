## 최종 검증

`main`에 반영한 뒤 그 브랜치에서 확인했습니다.

| 확인 | 결과 |
| --- | --- |
| `npm test` | 34개 통과 |
| `node bin/cairn.mjs check template` | 문제 0 |
| `node bin/cairn.mjs check .` | 문제 0 |
| 임시 폴더 `cairn init` → `cairn check` | 문제 0 |

`check .`가 내는 확인 항목은 아카이브한 `001-cairn-setup` 기록이 당시의 문서
경로를 담고 있어 나오는 것입니다. 아카이브는 그때의 기록이므로 문제로 보지
않습니다.
